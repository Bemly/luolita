什么是 Luolita？

Luolita（萝莉塔）是一个类似 Vue 的单文件组件生成器。它将 .luoli 文件中的三种语法分别编译为标准的 JavaScript、HTML 和 CSS：

  • coffee: — CoffeeScript → JavaScript（含 source map）
  • template: — Pug 模板 → HTML（变量自动桥接）
  • style: — Stylus → CSS

支持 Node.js 命令行和浏览器两种运行方式。

Node.js 使用

安装

$ pnpm add luolita # 或 $ npm install luolita

命令行

pnpm exec coffee luolita.coffee src/app.luoli -o dist/ -n app

选项

选项说明
-o, --output输出目录（默认 temp/）
-n, --name输出文件前缀
-q, --quiet关闭调试输出
-h, --help显示帮助信息

输出文件

编译后生成三个文件：

  • <name>.js — JavaScript（含 source map）
  • <name>.html — HTML 模板
  • <name>.css — CSS 样式

浏览器使用

浏览器 bundle 已内置 CoffeeScript、Pug、Stylus 运行时，零外部依赖，一个 <script> 标签即可使用。

API

方法说明
Luolita.compile(text, opts)编译 .luoli 文本，返回 Promise
Luolita.renderToDOM(text, target)编译并渲染到 DOM 元素
