# Changelog

## 0.1.0

Initial release.

- Language server for `.luoli` files (100% CoffeeScript)
- Real-time diagnostics (CoffeeScript, Pug, Stylus compilation errors)
- Document symbols (sections + variables)
- Code folding by section
- Hover information (section type, variable values)
- Auto-completion (section markers, variable names)
- TextMate syntax highlighting
